# tiktool Scoop bucket

```powershell
scoop bucket add tiktool https://github.com/tiktool/scoop-bucket
scoop install tiktool/mouse-keys-record-replay
```

Mouse Keys Record Replay records mouse and keyboard input with one shortcut and replays it once or on a loop.
Site: https://mouserec.com - source: https://github.com/tiktool/mouse-keys-record-replay

The manifest is bumped automatically from the latest GitHub release.
